심각합 -2 이하 → 손절·전량 매도 검토
📈 상승 단계 (합 기준)
유지합 0 이상 + 절대평균 0.5 이하 → 보유, 손절선 상향
관리합 +1 이상 → 보유, 트레일링 손절선 상향 점검
익절합 +2 이상 → 일부 익절 검토
과열합 +3 이상 → 절반 내외 익절, 트레일링 타이트하게
주의합 0 이상 + 절대평균 1 이상 → 흔들림 큼, 일부 익절 검토
75일선 이격률이 120을 넘으면 익절을 더 적극적으로.
⚠ 경계 신호
약화5일 합 < 10일 합 → 최근 힘 약해짐 (합 +1 이상이면 익절 쪽 경계)
횡보합 0 근처 + 절대평균 큼 → 출렁임 구간, 비중 축소 또는 관망
🌊 흔들림 비율 (5일 ÷ 10일 절대평균)
1.2 초과확대: 평소보다 크게 출렁이는 중
0.8~1.2비슷: 평소 수준
0.8 미만안정: 평소보다 조용해짐
방향은 알려주지 않아요. 합과 같이 보기: 확대 + 합 플러스 → 익절 쪽, 확대 + 합 마이너스 → 비중 축소 쪽, 안정 + 합 마이너스 → 조용히 밀리는 중이라 경계 유지.
🎯 눌림목 신호 (10일 기록 필요)
①10일 합 +1 이상 → 앞서 충분히 올랐음
②5일 합 -1 ~ 0 → 얕은 조정 (-1 이하면 하락 전환, 경고)
③5일/10일 비율 1.0 이하 → 조용한 조정
④당일 0 이상 → 반등 시작
후보①~③ 충족, ④ 대기
신호①~④ 모두 충족
가격 조건은 앱이 못 보니 위 체크리스트(20일선 위, 75일선 이격률 120 이하 등)와 함께 확인하세요.
💹 10일 가격 신호 (종가 기준)
▲ 고점 돌파현재가 > 직전 10일 최고 종가 → 매수 후보
▲ 눌림 반등고점 대비 -0.5~-2.0 ATR 조정 후 전일보다 상승 → 매수 후보
▼ 저점 이탈현재가 < 직전 10일 최저 종가 → 매도 경계, 손절선과 점검
▼ 평균 아래10일 평균 아래 + 고점 대비 -1.5 ATR 초과 → 비중 축소 검토
한 번에 하나만 표시돼요. 가격은 전일종가에서 ATR 변동을 거꾸로 계산한 근사값(≈)이고, 고가·저가가 아닌 종가 기준이에요.
